# Glosario oficial

| Término | Definición |
|---|---|
| **Turno** | Bloque horario reservable de una cancha (60 min fútbol 5; 90 min pádel/tenis). |
| **Reserva activa** | Reserva futura no cancelada; cuenta contra el límite del usuario en su semana calendario. Se libera al pasar el turno o cancelar. |
| **Grilla de turnos** | Bloques fijos desde las 8:00 por deporte (RN-17). |
| **Socio / No socio** | Tipo de usuario; define anticipación, límite y descuento. |
| **Precio base** | Valor de la cancha por turno guardado en el sistema. El descuento de socio y el recargo pico se calculan ambos sobre este valor. |
| **Horario pico** | 18:00–23:00 y sábados/domingos; recargo del 30%. |
| **Penalidad** | 50% del precio final del turno del usuario por cancelación tardía (< 24 h). Se registra como deuda. |
| **Deuda** | Monto pendiente de pago presencial; bloquea nuevas reservas hasta que el admin la marque pagada. |
| **Ausencia** | Falta o llegada > 15 min tarde, marcada por el administrador. |
| **Bloqueo** | Suspensión de 15 días para crear reservas tras 3 ausencias en 30 días. |
| **Lista de espera** | Cola de usuarios por un turno exacto ocupado (cancha + fecha + horario). |
| **Oferta de vacante** | Asignación automática al primer apto de la cola; vence a los 30 min o al inicio del turno, lo que ocurra primero. |
